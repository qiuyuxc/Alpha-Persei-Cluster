# 自选箱、奖励配置与概率掉落修复

背包使用自选箱时，旧实现对越界选项只记日志，仍扣掉箱子并返回成功；一个箱子提交两个相同或不同选项还会获得双份奖励。现在使用客户端的单选格式，每条请求必须提供一个从 1 开始的有效选项编号，奖励数量按该条请求消耗的箱数计算。同一箱子拆成多条合法请求时，各条选择仍独立生效。

使用配置、奖励列表或掉落表缺失及格式无效时返回失败，整批材料、奖励与待发通知由现有保存点恢复。2026 时迹回赠修正者自选券（30206）补齐同版客户端的 59 个选项。九种限时冷却剂按配置引用解析普通冷却剂的体力奖励。

矩阵常规补给等 `sub_type=507` 掉落箱的概率未命中会直接跳过该奖励；两字段旧配置仍表示必得奖励。每个箱子独立判定概率和权重抽取，保留显式的零次权重抽取。掉落箱拒绝自选参数。

29 项专项和 65 项开箱、资产及回执相关检查全部通过，使用完整测试库副本、真实 protobuf 和真实资产写入。覆盖六类自选箱、2026 自选券、限时冷却剂、概率边界、合法空掉落、重复条目、直接及嵌套调用、必要回复失败、另一 UID、持久化与 SQLite 完整性。67 个自选箱配置、三张掉落表和九条冷却剂引用与保存的对应客户端核对一致。
