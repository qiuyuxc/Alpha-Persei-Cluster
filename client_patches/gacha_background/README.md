历史卡池的一部分预制界面缺少大背景或引用已撤下的 PV。Build 307/321 的补丁只包装 `DrawBasePool.lua`，卡池 ID、固定 UP、探测规则和原始配置保持原值。

有现成同角色展示模板的历史池使用该模板，入场播放同角色的现有短动画；其余兼容池保留原布局，使用同角色的现有入场和循环动画补足背景。仍具备完整原生 PV 的卡池保持原展示，自选池和钥从池不经过这层适配。

视频首次解码前隐藏空画面，播放异常清除遮罩，停止的中间状态保留卡池背景。切换、关闭和销毁后使延迟播放及旧回调失效。专项测试使用原客户端的角色池、基础池和卡池配置字节码；两种脚本架构分别编译和验证。资源包构建确认每种架构的其它 10,267 个对象完全不变，并沿用已经修复的主页资源清单。

`compatibility.json` 和 `catalog.lua` 来自同版本预制界面、视频路径与现有同角色模板的审查；更换客户端版本时需重新检查。真机显示由用户验收。
